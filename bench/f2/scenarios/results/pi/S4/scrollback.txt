 ### Bug Report               

 File: simplelru/lru.go       
 Lines Affected: ~159-160     

 Why it is a bug:             
 In the Resize method, the loop condition for evicting elements is incorrect. The variable diff represents the          
 difference in size (oldSize - newSize). To reduce the cache size from oldSize to size, the loop should run exactly     
 diff times.                  

 The change goes from:        

 ```go                        
   for i := 0; i < diff; i++ { // Runs 'diff' times         
 ```                          

 to:                          

 ```go                        
   for i := 0; i <= diff; i++ { // Runs 'diff + 1' times    
 ```                          

 This causes the cache to evict one more element than requested, potentially making the resulting cache size one        
 smaller than the specified size.
